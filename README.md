# 🇬🇭 GhanaLearn

GhanaLearn is a modern offline-first educational platform designed for Ghanaian Junior High School students following the NaCCA-approved GES curriculum.

The platform combines advanced iOS-inspired glassmorphism UI, Gen Z aesthetics, interactive CBT quizzes, instant answer explanations, and mobile-first learning experiences into a single lightweight application.

---

# ✨ Features

- 📚 NaCCA-approved GES subjects
- 🧠 35 randomized quiz questions per subject
- ✅ Instant correct/wrong feedback
- 💡 Comprehensive answer explanations
- 📱 Mobile responsive design
- 🌐 Works online and offline
- 🎨 Advanced iOS glassmorphism interface
- ⚡ Fast single-file HTML architecture
- 🚀 Vercel deployment ready
- 💻 LiveCodes.io compatible

---
